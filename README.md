## 📖 About the Project

**TermTIX** is a lightweight terminal designed to reduce RAM consumption in Linux systems. Its main advantages include a tiny footprint of just 0.2 MB, a maximum RAM usage of only 25 MB, and easy configuration with just 3 parameters (created specifically for LungoOS).

## ✨ Features

| Advantage | Description |
| :--- | :--- |
| 🪶 **Lightweight** | The terminal size is just **0.2 MB** — an incredibly small footprint for a full-featured terminal. |
| 🧠 **RAM Efficiency** | Maximum RAM consumption is only **25 MB**, making it ideal for low-end machines. |
| ⚙️ **Simple Setup** | Just **3 parameters** for complete configuration — setup takes seconds. |
| 🚀 **High Performance** | Instant launch and response times thanks to its minimalist architecture. |
| 🎯 **Built for LungoOS** | Specially optimized for the lightweight LungoOS operating system. |
| 📦 **Arch-Optimized** | Full compatibility with Arch Linux and its ecosystem (Pacman, AUR). |
| 🔒 **Stability** | Reliable performance with no unnecessary dependencies or heavy libraries. |
| 💡 **Intuitive** | Simple and clean interface that requires no manuals to learn. |

### 🔧 Installation

**Requirements:**

```bash
sudo pacman -S gtk3 vte3 base-devel pkg-config
```

**LungoOS (XungoOS):**

```bash
nova -S termtix
```

**Arch Linux:**
Before downloading, you need to add the LungoOS repositories to pacman (a guide for this is available in the lungo-repo repository).
```bash
sudo pacman -S termtix
```
